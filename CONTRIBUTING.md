# Contributing to Ghostwriter

Ghostwriter is built for people who want creator infrastructure they can inspect, modify, and own.

## Workflow

1. Fork the repository and create a focused branch.
2. Keep provider-specific behavior behind adapters.
3. Add or update tests for behavioral changes.
4. Run `npm run check` before opening a pull request.
5. Keep secrets, access tokens, and generated private assets out of commits.

Prefer small, reviewable pull requests. For large architectural changes, open an issue first so the interface can be discussed before implementation.
